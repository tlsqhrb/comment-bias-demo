📌 Comment-Bias-Demo
YouTube 댓글 프레이밍 편향 분석 도구 (FastAPI + KoELECTRA)

이 프로젝트는 온라인 댓글 프레이밍 편향을 완화하기 위해 설계된 데모 웹 애플리케이션입니다.
사용자가 댓글을 보기 전에 먼저 자신의 의견을 작성하고, 이후 YouTube 댓글을 자동 수집하여
찬성 / 반대 / 중립 비율을 분석해 실제 여론 구조를 시각적으로 제공합니다.

🚀 주요 기능
✅ 1. YouTube 영상 댓글 자동 수집

YouTube Data API를 활용해 영상 댓글 수집

URL 또는 영상 ID 둘 다 입력 가능

최대 50개 댓글 수집 (필요시 확장 가능)

✅ 2. stance 분류 (찬성 / 반대 / 중립)

한국어 기반 KoELECTRA 모델로 문장 입장을 분류

직접 구축한 stance_dataset.csv 데이터로 추가 학습한 모델 사용

✅ 3. 웹 데모 인터페이스 제공

단순하고 직관적인 index.html UI

“내 의견 → 댓글 분석” 흐름을 통해 프레이밍 편향 억제

찬반중립 비율을 태그 형태로 시각화

댓글별 stance 라벨 표시
